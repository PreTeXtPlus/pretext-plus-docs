# Markdown-Style Projects

A Markdown-style project lets you write in an extended Markdown syntax. PreTeXt.Plus compiles this into PreTeXt for multi-format output.

## When to Use This Type

- You want to write quickly with minimal markup
- Your document has little mathematical content
- You are already comfortable with Markdown
