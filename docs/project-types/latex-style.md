# LaTeX-Style Projects

A LaTeX-style project lets you write your document using LaTeX-like syntax. PreTeXt.Plus automatically converts this to valid PreTeXt XML behind the scenes, so you get the benefits of PreTeXt's structured output while writing in a familiar style if you're coming from a LaTeX background.

## When to Use This Type

- You are coming from a LaTeX background.
- You already have LaTeX source you want to convert.
- You prefer LaTeX's familiar syntax.

See the [LaTeX-style PreTeXt documentation](/how-to/latex-style/) for details on the supported syntax and features.
