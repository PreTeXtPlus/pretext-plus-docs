# LaTeX-Style Projects

A LaTeX-style project lets you write your document using LaTeX-like syntax. PreTeXt.Plus compiles this into PreTeXt, which can then be built to HTML, PDF, or any other supported output format.

## When to Use This Type

- You are coming from a LaTeX background
- You already have LaTeX source you want to convert
- You prefer LaTeX's familiar syntax for math-heavy documents
