# Roadmap

Features planned or in active development for PreTeXt.Plus.  We are working hard to bring a fully featured version of PreTeXt.Plus to life, and this roadmap will evolve as we make progress.  Check back often for updates!

:::note
This roadmap reflects current plans and is subject to change.
:::

## Coming Soon

- Multiple document types: books, articles, course packets, and slideshows
- Importing existing LaTeX, Markdown, and PreTeXt projects
- Include uploaded images as well as generated diagrams using TikZ and Asymptote
- Support for more output formats, including PDF, EPUB, SCORM, and Braille
- Improved conversions between LaTeX-style and Markdown-style projects to PreTeXt (please share feedback on what features are most important to you!)
- More customization options (PreTeXt publication file options)

## Planned

- Collaborative editing features, including real-time co-authoring and commenting
- Visual editing mode for users who prefer a WYSIWYG interface

## Other ideas?

We want to make PreTeXt.Plus as useful as possible for the community. If you have ideas for features or improvements, please share them with us! Drop us a line at [feedback@pretext.plus](mailto:feedback@pretext.plus)
