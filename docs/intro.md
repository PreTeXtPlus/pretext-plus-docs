# Introduction

PreTeXt.Plus is an online, cloud-based authoring environment for [PreTeXt](https://pretextbook.org) projects. No need to install anything or manage GitHub repositories or codespaces.

Why *Plus*?  In addition to being a space where you can author PreTeXt documents using the standard PreTeXt XML, PreTeXt.Plus offers lets you write your documents using markups similar to LaTeX and Markdown. This makes it easier to produce books, articles, and course materials in the syntax that fits your workflow.


## Getting Started

Even without creating an account, you can [try PreTeXt.Plus](https://pretext.plus/tryit) using any of our markup styles. When you are ready, create a free account and create your first project.

## About This Documentation

This documentation covers features unique to PreTeXt.Plus, including specifications for the LaTeX-style and Markdown-style project types. It does not cover how to write PreTeXt itself. For that, refer to the [official PreTeXt documentation](https://pretextbook.org/doc/guide/html/).
