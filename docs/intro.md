# Introduction to PreTeXt.Plus

PreTeXt.Plus is an enhanced authoring environment for [PreTeXt](https://pretextbook.org) documents. It extends PreTeXt with additional project types and authoring styles, making it easier to write books, articles, and course materials using familiar syntax — whether you prefer LaTeX, Markdown, or native PreTeXt.

## What PreTeXt.Plus Is Not

PreTeXt.Plus is **not** a replacement for PreTeXt, and this documentation does **not** cover how to write PreTeXt. For that, refer to the [official PreTeXt documentation](https://pretextbook.org/doc/guide/html/).

What PreTeXt.Plus adds:

- Multiple **project types** suited to different workflows
- **LaTeX-style** and **Markdown-style** authoring that compiles to PreTeXt
- A streamlined project creation experience
- Additional tooling and VS Code integration
