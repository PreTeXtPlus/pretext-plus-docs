# Introduction

PreTeXt.Plus is an online, cloud-based authoring environment for [PreTeXt](https://pretextbook.org) projects. There is nothing to install, no GitHub repository to manage, and no codespace to spin up — you write in your browser and PreTeXt.Plus builds and hosts the result.

## Why *Plus*?

In addition to being a place to write standard PreTeXt XML, PreTeXt.Plus lets you author the same document using **LaTeX-style** or **Markdown-style** markup. Both are converted to real PreTeXt before anything is built, so you get PreTeXt's accessible, multi-format output while writing in whichever syntax fits your habits.

A single project can even mix all three: one section in PreTeXt, the next in LaTeX, a third in Markdown. See [Writing](/writing/) for the details.

## Getting started

- [Try it without an account](/getting-started/try-it/) — a scratch project preloaded with all three markup styles.
- [Create your first project](/getting-started/creating-a-project/) — from scratch, from a template, or by importing what you already have.

## What this documentation covers

These pages document what is **unique to PreTeXt.Plus**: the interface, projects and templates, collaborators, assets, build outputs and publishing, and the specifications for LaTeX-style and Markdown-style PreTeXt.

They do **not** teach the PreTeXt language itself. For that, use the official [PreTeXt Author's Guide](https://pretextbook.org/doc/guide/html/).
