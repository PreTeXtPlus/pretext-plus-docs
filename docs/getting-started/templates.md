# Starting from a Template

A template is a complete project — divisions, assets, preamble, and build outputs — curated by the PreTeXt.Plus team as a starting point.

## Using a template

1. Click **+ New project**, then **Start project from template**.
2. Each template is listed with a badge showing its markup style (PreTeXt, LaTeX-style, or Markdown-style), its title, and a short description.
3. Click **Use this template**.

The template is deep-copied into your account and the editor opens on the copy. The new project is named `<Template name> (generated from template)`; rename it from the editor's title field.

Everything is yours from that point on: the copy has its own divisions, its own uploaded asset files, and its own output configuration. Editing it never affects the template or anyone else's copy.

## What is and is not carried over

| Carried over | Not carried over |
|---|---|
| All divisions and their source | Build history |
| All assets (images and their files) | Published status — a copy is not entitled to the original's public URLs |
| The document preamble (`docinfo`) | The template flag |
| Output configuration (names and formats) | |

Because outputs are copied but their builds are not, a fresh template project shows its outputs as **Not built**. Click **Build** on each one you want. See [Build outputs](/building/outputs/).

## Quota

A project created from a template counts against your [project quota](/getting-started/accounts-and-limits/) like any other.

## If no templates are listed

The template gallery is curated, and is still growing. If the dialog says no templates are available yet, use **New empty document** or [import](/getting-started/importing/) instead — and tell us what template would have helped at [feedback@pretext.plus](mailto:feedback@pretext.plus).
