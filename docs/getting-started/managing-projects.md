# Managing Projects

## The Projects Dashboard

Your **Projects Dashboard** — **Projects** in the site's navigation bar, or **Account ▸ Projects** in the editor — shows your five most recently edited projects, followed by up to five **Shared with me**: projects where you are a [collaborator](/editor/collaborators/). **Show more projects →** and **Show more shared projects →** open the full lists.

Use the search box at the top to find a project by title, among both your own and shared projects.

Each project card shows the project's visibility and the state of each of its outputs, with two buttons: **Manage** opens the project's page, and **Write** opens the editor.

## The project page

Everything that happens outside the editor lives on the project's page:

| | |
|---|---|
| **Visibility on your public profile** | Private, Unlisted, or Public. See [Project visibility](/building/publishing/#project-visibility). |
| **Description** | A short summary, also shown on your public profile. Change it with **Edit description**. |
| **Write** | Opens the [editor](/editor/overview/). **Manage project** in the editor's top bar brings you back here. |
| **Make copy** | Duplicates the project into your account. See below. |
| **Download source** | A zip that PreTeXt-CLI can build as is. See [Download source](/building/publishing/#download-source). |
| **Share source** | A read-only view of the source that others can copy. Not offered while the project is Private. |
| **Outputs** | Configure, build, and publish. See [Build outputs](/building/outputs/) and [Build settings](/building/build-settings/). |
| **Collaborators** | Invite co-authors, or hand the project to one of them. See [Collaborators](/editor/collaborators/). |
| **Assets** | A gallery of the project's images. Add and edit them in the editor — see [Assets](/editor/assets/). |

## Copying a project

**Make copy** creates **Copy of *title*** in your account, with its own divisions, snippets, assets, preamble, and output configuration. The copy starts out **Private**, with no builds and nothing published. Copied assets count toward your [asset limit](/getting-started/accounts-and-limits/).

You can copy someone else's project too, as long as it is not Private: open its **Share source** link and choose **copy this project**.

## Deleting a project

**Delete this project**, at the bottom of the project page, removes the project and all of its build outputs. It cannot be undone.

Only the owner can delete a project. To leave a project with a co-author instead, [transfer ownership](/editor/collaborators/#transferring-ownership) first.
